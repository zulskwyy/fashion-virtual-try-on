# Public Release Notes — V10

V10 is an experimental public prototype.

The repository does not contain secrets, model weights, or user camera captures.

The default VTON backend is a third-party public Gradio Space. Its availability, quotas, endpoint contract, and license are external dependencies and may change.

Do not treat the prototype as a production identity, privacy, or commerce system without adding authentication, abuse controls, rate limits, persistent storage, observability, and a provider arrangement appropriate for the intended use.
